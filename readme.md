# Automated Tests for the https://edostavka.by

## General info:

* Test 1. Service menu navigation. 
* Test 2. Catalog navigation. 
* Test 3. Product search.
* Test 4. Login to account.


## Technologies:

* Java 17
* Gradle
* TestNG 7.10.2
* Selenium
* Allure 2.25.0
* Apache Log4j 2.24.3
* Project Lombok 1.18.36

## Launch:

to run default test go to project dir and run:

```
gradle clean test
```
